## 🎨 Customization

### Change Primary Color
```css
/* In style.css */
:root {
    --primary-glow: #YOUR_COLOR;
}
```

### Adjust Animation Speed
```css
/* Find the animation */
animation: gridMove 20s linear infinite;
/* Change 20s to your preference */
```

### Modify Glow Intensity
```css
/* Adjust box-shadow values */
--glow-md: 0 0 20px rgba(0, 212, 255, 0.4);
/* Increase 0.4 for more glow */
```
